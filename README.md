# ApiCheck Zapier Integration

Connect ApiCheck to 6000+ apps via Zapier. Validate addresses, verify emails and phone numbers in your workflows.

## Features

### Actions
- **Lookup Address** - Look up an address by postal code and house number (NL, LU)
- **Verify Email** - Check if an email is valid, disposable, or greylisted
- **Verify Phone** - Validate phone numbers and get formatted output

### Searches
- **Global Search** - Search for addresses, streets, cities, or postal codes
- **Search Address** - Find addresses using IDs from other searches

## Installation

This integration is published on Zapier. Search for "ApiCheck" in the Zapier app directory.

## Usage

1. Go to [Zapier](https://zapier.com) and create a new Zap
2. Search for "ApiCheck" and connect your account
3. Enter your API key from [app.apicheck.nl](https://app.apicheck.nl)
4. Choose an action: Lookup Address, Verify Email, or Verify Phone

## Example Zaps

- **New form submission → Verify email → Add to mailing list**
- **New customer → Lookup address → Create shipping label**
- **New lead → Verify phone → Send SMS**
